# 🐱 Meao Dictionary

A cute, interactive offline dictionary app featuring an adorable lofi cat interface.

## ✨ Features

- **Adorable Cat Interface**: Meet Meao, your friendly dictionary cat with blinking eyes!
- **Interactive Animations**: Click the cat to see animations and reveal the search interface
- **Real Dictionary APIs**: Powered by Free Dictionary API (English) and Jisho.org API (Japanese)
- **True Bilingual Dictionary**: Cross-language translations with each search
- **Smart Translation**: English words show Japanese translations, Japanese words show English translations
- **Audio Pronunciation**: Listen to word pronunciations (English)
- **Smart Memory**: Local storage for search history and bookmarked words
- **JLPT Support**: Japanese words show JLPT levels and common word indicators
- **Lofi Aesthetic**: Warm, cozy design with smooth animations
- **Responsive Design**: Works beautifully on desktop and mobile

## 🎮 How to Use

1. **Open `index.html`** in your web browser
2. **Click on Meao** (the cute cat) to activate the search interface
3. **Type any word** you want to look up
4. **Choose your language** using the language toggle buttons (English/日本語)
5. **Press Enter or click the search button** to find definitions
6. **See cross-language translations** 🌍 - English words show Japanese, Japanese words show English
7. **Click the audio button** 🔊 to hear pronunciations (English words)
8. **Bookmark words** ⭐ for later study
9. **View your history** 📚 to see previously searched words

## 🎨 Interface Features

### Cat Animations
- **Gentle Floating**: Continuous gentle movement and breathing
- **Blinking Eyes**: Realistic blinking animation with manual triggers
- **Interactive Reactions**: Wiggle when clicked, happy bounce when found words
- **Hover Effects**: Cat scales up slightly when you hover over it

### Dictionary Features
- **Real-time Search**: Instant results from live dictionary APIs
- **Cross-Language Translation**: Every search shows both original meaning and translation
- **English Support**: Complete definitions, parts of speech, examples, audio + Japanese translation
- **Japanese Support**: Hiragana, katakana, kanji with JLPT levels + English translation
- **Smart Storage**: Automatically saves search history and bookmarks locally
- **Audio Playback**: Pronunciation audio for English words
- **Fallback System**: Works even when translation API is unavailable

## 🚀 Getting Started

Simply open the `index.html` file in any modern web browser. No installation or setup required!

```bash
# Clone or download the project
cd meao-dictionary
open index.html  # macOS
# or double-click index.html in file explorer
```
